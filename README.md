# Гравитационная адача N тел

Материальные точки разной массы двигают друг друга благодаря силе тяготения.  
Задача кажется тривиальной, но с увеличением числа точек растёт сложность расчётов ($O(N^2)$)

Алгоритм Барнса-Хата (Quad Tree) позволяет оптимизировать задачу в ущерб точности (сложность $N log N$).  
Квадродерево эффективно только для большого количества тел

Суть алгоритма:
- Если представить несколько тел как единое тело в точке их центра масс с их суммарной массой, сила тяготения вызванная им будет примерно равна равнодействующей сил тяготения всех тел в отдельности
- Пространство разбивается на иерархическую сетку, из секторов строится дерево
- Каждый сектор содержит либо тело, либо ещё 4 сектора (отсюда и название -- квадродерево)
- Для каждого сектора считается центр масс и суммарная масса тел 
- Остаётся только задать точность. При максимальной точности оптимизации не будет (каждый узел -- лист с одним телом)
